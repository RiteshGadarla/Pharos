# The staged sample image

`synthetic_scene.tif` is committed to the repository on purpose, and it is
the only NetCDF or GeoTIFF fixture that is. Everything else under
`data/fixtures/` is generated by `scripts/make_synthetic_data.py` and
stays out of git.

It is here so that a fresh clone has a SAR scene to process immediately:

```
python scripts/make_synthetic_data.py --list     # nothing else needed for this
python scripts/process_sample.py
```

No dataset download, no account registration, no Docker, no database.

## What it is

A 512x512, single band, calibrated sigma0 (linear power) GeoTIFF at 10m
pixel spacing, CRS EPSG:32642 (UTM zone 42N), standing in for a Sentinel-1
GRD acquisition over the open Arabian Sea off India's west coast. It sits
inside the same offshore domain as the drift forcing fixtures (16-18N,
67-69E), so a detection from this scene can drive the backward ensemble
without any particle ever crossing real coastline.

Band 1 is read as VV. `services/detection/render.py` is the one place the
sigma0 to dB to 8-bit conversion happens, so the scene is stored the way a
real calibrated product would be, not pre-rendered.

## What is real in it and what is not

**Real:** the slick's texture. The oil pixels are genuine Sentinel-1A
backscatter and speckle from an actual Persian Gulf slick, composited in
from a CC BY 4.0 dataset and re-anchored to this scene's background sigma0
level. See `real_oil_texture/ATTRIBUTION.md` for the source, the license
and why that particular patch was chosen.

**Not real:** the geolocation, the acquisition time (2026-01-15T02:30:00Z)
and the surrounding sea. Those are synthetic. The coordinates are
illustrative and this is not a real incident. Real Sentinel-1 access is
blocked on the account registrations in PLAN.md section 4A.

This split is stated the same way in the UI, in the dossier's provenance
page and in the README, rather than only here.

## Rebuilding or replacing it

The generator is `scripts/make_fixture_scene.py`, driven through the single
entry point:

```
python scripts/make_synthetic_data.py --only scene --force
```

It is fully seeded (`SEED = 26143`), so a rebuild on any machine produces
the same file.

To process your own scene instead, leave this one alone and pass a path:

```
python scripts/process_sample.py --scene /path/to/your_scene.tif
```

Band 1 must be calibrated sigma0 in linear power. A scene already in dB,
or raw DN, will be read as if it were linear power and will degrade the
model's output silently rather than erroring. That trap is documented at
the top of `services/detection/render.py`.
